# Восстановление пароля в интернет-банке

Учебный документ для проверки агента на другом тексте. Версия 0.3, черновик.

## Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Самостоятельное восстановление пароля |
| **Продукт** | Интернет-банк для физических лиц |
| **Влияние на ИС** | Интернет-банк, сервис SMS, сервис аутентификации |

## Цели
Снизить число обращений в контакт-центр по поводу забытого пароля.

## Функциональные требования

* **ВП-1.** Клиент запрашивает восстановление по номеру телефона или ИИН.
* **ВП-2.** Система отправляет на телефон клиента одноразовый код из 6 цифр. Код действует 5 минут.
* **ВП-3.** После трёх неверных вводов кода восстановление блокируется на сутки.
* **ВП-4.** Клиент задаёт новый пароль. Пароль должен быть надёжным.
* **ВП-5.** После смены пароля все активные сессии клиента завершаются, кроме текущей.
* **ВП-6.** Код можно запросить повторно не чаще одного раза в минуту, но не более 5 раз в сутки.
* **ВП-7.** После пяти неверных вводов кода восстановление блокируется на 30 минут.

## Нефункциональные требования
Страница восстановления должна открываться быстро и быть удобной для пользователя.
Сервис должен работать без сбоев.

## Требования к интеграции
Отправка SMS — через существующий шлюз (см. документацию шлюза). Ответ шлюза не логируется.

## Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Клиент с подтверждённым телефоном | Запросить восстановление по ИИН | Пришло SMS с кодом |
| Код отправлен 4 минуты назад | Ввести верный код | Открыт экран нового пароля |
| Код введён неверно 3 раза | Ввести верный код | Восстановление заблокировано на 30 минут |
